# JavaScript Day 01 — Code and Output

## Exercise 1 — Basic Output

### Task

Write JavaScript that prints:

```text
Hello World!
```

### Code

```javascript
console.log("Hello World");
```

### Output

```text
Hello World
```

---

## Exercise 2 — Personal Introduction

### Task

Write four separate `console.log()` statements that display:

- My name is ...
- I am learning JavaScript.
- I want to become a Full-Stack Developer.
- JavaScript is my next learning step.

Use your own information.

### Code

```javascript
console.log("My name is Abishek.");
console.log("I am learning JavaScript.");
console.log("I wnat to become a full-stack developer.");
console.log("JavaScript is my next learning step.");
```

### Output

```text
My name is Abishek.
I am learning JavaScript.
I wnat to become a full-stack developer.
JavaScript is my next learning step.
```

---

## Exercise 3 — Multiple Values

### Task

Print a string, a number, and a boolean value.

### Code

```javascript
console.log("JavaScript");
console.log(100);
console.log(true);
```

### Output

```text
JavaScript
100
true
```

---

## Exercise 4 — Comments

### Task

Practice single-line and multi-line comments.

### Code

```javascript
// Hi, this is single-line comment

/*
Hi,
This is Multiline Comment
*/

console.log("Single line comment");
console.log("Multi-line comment");
```

### Output

```text
Single line comment
Multi-line comment
```
