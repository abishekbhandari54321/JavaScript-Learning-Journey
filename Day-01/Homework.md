# JavaScript Day 01 — Homework & Knowledge Check

## Q1. What is JavaScript?

### Answer

JavaScript is a programming language used to make web pages and web applications dynamic and interactive.

It is used to add behavior and functionality to websites.

---

## Q2. Why is JavaScript important in web development?

### Answer

JavaScript is important because it makes web pages dynamic and interactive.

It can also be used for both frontend and backend development.

---

## Q3. What is the main difference between HTML, CSS, and JavaScript?

### Answer

- **HTML** provides the structure of a webpage.
- **CSS** controls the appearance and style of a webpage.
- **JavaScript** adds behavior, functionality, and interactivity to a webpage.

Easy way to remember:

```text
HTML       → Structure
CSS        → Appearance
JavaScript → Behavior
```

---

## Q4. Where can JavaScript run? Name two environments.

### Answer

JavaScript can run in different environments.

Two important environments are:

1. Browser
2. Node.js

---

## Q5. What is Node.js?

### Answer

Node.js is a JavaScript runtime environment that allows JavaScript to run outside the browser.

It is commonly used for backend development.

---

## Q6. What does `console.log()` do?

### Answer

`console.log()` is used to display a value or message in the console.

Example:

```javascript
console.log("Hello World");
```

Output:

```text
Hello World
```

---

## Q7. Is JavaScript case-sensitive?

### Answer

Yes, JavaScript is case-sensitive.

This means uppercase and lowercase letters are treated as different.

For example:

```javascript
console.log("Hello");
```

and:

```javascript
Console.log("Hello");
```

are different.

---

## Q8. What is the purpose of `//`?

### Answer

`//` is used to create a single-line comment in JavaScript.

Example:

```javascript
// This is a single-line comment
```

JavaScript ignores the comment when the program runs.

---

## Q9. What is the purpose of `/* ... */`?

### Answer

`/* ... */` is used to create a multi-line comment in JavaScript.

Example:

```javascript
/*
This is a
multi-line comment
*/
```

JavaScript ignores the comment when the program runs.

---

## Q10. What is the difference between browser JavaScript and Node.js at a high level?

### Answer

**Browser JavaScript** runs inside a web browser using the browser's JavaScript engine.

**Node.js** runs JavaScript outside the browser using the Node.js runtime environment.

In simple words:

```text
Browser JavaScript → JavaScript runs inside the browser.

Node.js            → JavaScript runs outside the browser.
```
